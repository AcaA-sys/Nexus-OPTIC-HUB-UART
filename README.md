# Nexus-Sense-FD — Интеллектуальный сенсорный хаб экосистемы AcaA-sys

**Nexus-Sense-FD** — это специализированный периферийный узел (Slave Node) на базе микроконтроллера STM32G431CBT, предназначенный для сбора телеметрии, контроля параметров окружающей среды и управления вспомогательными механизмами в прецизионных ЧПУ-системах и SMD-установщиках (OpenPnP).

## 🛠 Технические характеристики (Hardware)

*   **Микроконтроллер:** STM32G431CBT6 (Ядро ARM Cortex-M4F, частота 170 МГц.
*   **Интерфейс связи:** Высокоскоростная шина CAN FD (скорость передачи данных до 5 Мбит/с).
*   **Изоляция линии:** Гальванически изолированный птрансивер TD541.
*   **Защита шины:** Синфазный дроссель ACT45B-510-2P для фильтрации ЭМС-помех + защитные TVS-диоды.
*   **Согласование:** Встроенный терминатор линии 120 Ом для подавления отражений сигнала.

## ⚡ Архитектура питания и аналоговый тракт

*   **Основной DC/DC:** Импульсный стабилизатор Mornsun K7805M-1000R3.
*   **Логическое питание:** LDO-регулятор MC5219-3.3YMS-TR для питания цифровой части (+3V3).
*   **Аналоговый референс:** Источник опорного напряжения (ИОН) REF3030 (выход 3.0V с низким температурным дрейфом), подключенный к выводу `VDDA`.

## 🔍 Интегрированные датчики и интерфейсы

*   **Акустическая диагностика:** Цифровой MEMS-микрофон SPH0645LM4H (интерфейс I2S) для непрерывного анализа спектра шумов и предикативного поиска износа механики.
*   **Климат-контроль:** Цифровой датчик температуры и влажности SHT35 (интерфейс I2C).
*   **Термомониторинг:** Интерфейс для подключения цифрового датчика температуры корпуса/радиатора DS18B20.
*   **Позиционирование:** Разъем J7 для подключения внешнего акселерометра ADXL355 (интерфейс SPI).
*   **Оптический канал:** Разъемы J2 для подключения датчиков освещенности/позиционирования OPT3001.
*   **Измеритель растояния:** Интерфейс для подключения лазерного измерительного датчика Panasonic HG-C1030 (дистанция измерения 30±5 мм, точность/повторяемость до 10 мкм).

## 📌 Инженерные решения

1.  **Совмещенный интерфейс (Индикация + Адресация):** Линии, подключенные к светодиодам `B3`, `B4` и `A15`, используются в момент старта МК для считывания аппаратного ID-адреса узла в CAN-сети (через физические джамперы/перемычки), после чего переключаются в режим стандартных выходов индикации статуса.
2.  **Универсальный интерфейс (Вывод B10):** Высокоскоростной вывод `PB10` выведен на штыревой разъем (PLS) для подключения опциональных переходных плат. Спроектирован на перспективу под синхроимпульс промышленной камеры (съемка «на лету» в OpenPnP).
3.  **Локальное управление:** Физическая кнопка `KEY` для ручного переключения режимов работы и принудительного тестирования связи.
